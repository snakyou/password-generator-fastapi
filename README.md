# Криптографически стойкий генератор паролей

Веб-приложение для генерации надежных и непредсказуемых паролей. Проект построен на раздельной архитектуре с использованием современного бэкенда на Python и интерактивного фронтенда.

## Особенности проекта
* **Высокая безопасность**: вместо стандартного модуля `random` используется криптографический модуль `secrets` (CSPRNG), устойчивый к предсказанию алгоритмов.
* **Интерактивный интерфейс**: удобная настройка длины пароля ползунком и выбор параметров с помощью чекбоксов.
* **Удобный UX**: копирование готового пароля в буфер обмена в один клик с визуальным уведомлением.
* **Чистая архитектура**: проект разделен на независимые слои (HTML, CSS, JS), а раздача статики и рендеринг шаблонов реализованы через шаблонизатор **Jinja2**.

## Стек технологий
* **Backend**: Python 3, FastAPI, Uvicorn, Jinja2, Secrets
* **Frontend**: HTML5, CSS3 (Modern Flexbox + Анимации), JavaScript (Async/Await Fetch API)

## Инструкция по запуску

### 1. Клонируйте репозиторий
```bash
git clone [https://github.com](https://github.com/snakyou/password-generator-fastapi.git)
cd password-generator-fastapi
```

### 2. Установите зависимости
```bash
pip install fastapi uvicorn jinja2
```

### 3. Запустите сервер
```bash
python main.py
```
После этого откройте браузер и перейдите по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)
